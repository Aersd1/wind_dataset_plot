# 224 点格拉姆角场探索

此目录独立于原有 Figure 5/论文绘图流程。默认从已确认的 `aligned_segments` 层选择清单中的**全部 131 个风场**，每场最多抽取 32 个连续、非恒定的窗口。一个窗口是 **224 个连续 15 分钟瞬时功率点，即 56 小时**；缺测、重复时间戳、文件边界和切段边界都不跨越。原始功率先除以对应风场的额定容量，得到容量因子 CF。

## 在服务器运行

仓库根目录：

```bash
python -m pip install -e .
python -m gaf_224 --inspect
python -m gaf_224 --output-dir gaf_224/results
```

`--inspect` 只核对清单、容量和气候元数据，本机也能运行；正式命令需服务器能读取 `publication_config.json` 所指的原始功率 CSV。服务器目录改变时，修改该文件的 `inputs.path_prefix_map`。若想重跑，指定一个新的空输出目录。`config.json` 中 `farms: "all"` 表示当前清单的所有风场，也可改为明确的 ID 列表；每场窗口数、步长和聚类数也可调整。各气候组的数据来源并不平衡，跨组差异不能直接归因于气候。

默认只保留容量因子极差 `max(CF)-min(CF) > 1e-6` 的窗口，因此恒定及数值上近乎恒定的 224 点窗口不会被抽取。`farm_audit.csv` 记录每场候选位置、越界排除数、恒定排除数、合格窗口数和实际抽取数。如果某场没有合格窗口，程序会报出该场 ID 并停止，避免在“全部风场”的名义下悄悄漏掉它。

## 转换与分析口径

每个窗口导出两类灰度 `224×224` GASF 图：

- `images/fixed/`：固定归一化 `x = 2CF - 1`，保留出力水平和形状；
- `images/shape/`：窗口内最小最大值归一化，主要比较形状。

角场定义为 `GASF(i,j) = cos(arccos(x_i) + arccos(x_j))`。计算指标时，先把每张 224×224 图按 7×7 区块取均值，得到 32×32 特征，再用 KMeans **不看气候标签**聚类；PCA 二维坐标只用于展示。两个尺度分别聚类。各场窗口沿其可用连续片段均匀选择，候选窗口不重叠。`windows.csv` 保留原始气候、来源、海陆类型、容量、CF 均值和范围以供审查。

`examples/gaf_examples_*.png/pdf` 分页展示每场一个真实窗口的时序、固定尺度角场和形状尺度角场。`fixed/` 与 `shape/` 分别输出聚类与气候、来源、海陆类型的交叉表，逐场聚类计数、PCA 图以及调整互信息（AMI）。AMI 是描述性指标；每场多个窗口并非独立风场，且气候与来源并未完全平衡。因此图和 AMI 只能帮助发现值得继续检验的结构，不能证明气候成因。`climate_within_nrel_wtk` 额外只在同一 NREL 来源内比较有样本的气候组。

此仓库目前没有原始 15 分钟功率片段，本地无法产生真实 GAF 图或报告实际分离程度。不要用测试用的合成序列代替研究结果。
